# RoEmpire

Source code of **RoEmpire**, a world-map conquest game on Roblox by RoEmpire Studios.

This repository holds the game's scripts only (Luau), laid out by where they live in the place:
`ReplicatedStorage`, `ServerScriptService` and `StarterPlayer`. Art, sounds and other assets are not
included; they belong to RoEmpire Studios and are not covered by the licence below.
